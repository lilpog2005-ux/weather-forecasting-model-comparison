# Weather Forecasting Model Comparison

Time series forecasting project comparing statistical, machine learning, and deep learning models for seasonal weather temperature prediction.

## Project Features
- Time series preprocessing and analysis
- Seasonal decomposition and trend analysis
- Forecasting using statistical and ML models
- Deep learning forecasting with LSTM, GRU, and CNN
- Model performance comparison and evaluation
- Forecasting visualizations and analytical reporting

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- TensorFlow / Keras
- Statsmodels
- Matplotlib
- Seaborn
- Jupyter Notebook

## Models Implemented
- ARIMA
- Linear Regression
- Random Forest
- Gradient Boosting
- LSTM
- GRU
- CNN
